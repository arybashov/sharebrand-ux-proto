# ShareBrand — прототип мини-аппа промоутера

Кликабельный HTML/CSS/JS-прототип пользовательского флоу ShareBrand (согласие → анкета/квиз →
запись голоса → каталог → результат), в трёх визуальных и процедурных вариантах:

- **Coral · Voice** — полный флоу (эталон)
- **Telegram-native** — максимально сжатая процедура, всё на одном экране
- **Bold · Gamified** — быстрый quest-квиз с прогрессом и наградой

Открыть `index.html` — сравнение всех трёх вариантов рядом (каждая панель кликается независимо,
можно тянуть за уголок, чтобы менять размер). `prototype.html` — сам прототип, принимает
`?variant=coral|native|bold` в query.

Данные везде фейковые, реальной бизнес-логики или секретов нет.
